\section{Evaluation Methodology}
The main focus of this thesis is it to determine how the use of the passage retrieval module affects the retrieval accuracy and generation quality of ScholarCopilot. ScholarCopilot retains its original backbone model \mono{Qwen2.5-7B} \cite{an2024qwen2}. Since the retriever of the passage retrieval module is implemented with Batched Self-Consistency, it is required to follow multiple permutations of the same instruction during inference reliably and consistently (see \cite{korikov2025batched}). Instruction tuned models, that is, LLMs that are fine-tuned on (\mono{instruction}, \mono{desired-output}) pairs, are more successful at following instructions closely rather than just minimizing the next token prediction error \cite{shengyu2025instruction}. To make use of this, the PR module uses the instruction-tuned variant of the Qwen2.5 model, \mono{Qwen2.5-7B-Instruct} \cite{an2024qwen2}, as the passage retriever. Even though it has been shown that instruction tuned models may not fully utilize given instructions and are instead just good at learning the specified output format \cite{kung2023followInstructions}, this ability alone is valuable enough for the automated parsing of an LLMs' response to justify using an instruction tuned model (especially when using Batched Self-Consistency which greatly increases the number of responses that need to be parsed).

\section{Single-Step Retrieval}\label{retrieval-evaluation}
With ScholarCopilot as baseline, I evaluated the impact of using the PR module on the retrieval performance for a variety of retrieval contexts. To this end, I introduce the \emph{single-step retrieval} task which aims to assess the models accuracy when resolving a single \mono{[RET]} token during generation. This task closely follows the evaluation methodology used by \cite{wang2025scholarcopilot}. Single-step retrieval is evaluated using the Recall@$k$ metric, which is given as the fraction of cases where the ground truth document appears in the top-$k$ retrieved documents \cite{wang2025scholarcopilot}. As outlined in \refsec{dataset}, the model is given the left-hand context of a citation drawn from an existing paper, together with the cited document as the ground truth. A retrieval token is appended to this context before the resulting sequence is passed to ScholarCopilot, causing the model to compute a representation of the \mono{[RET]} token based on the given context. This representation is then used to compute a distribution over the ScholarCopilot retrieval corpus that measures the relevance of each document in the corpus to the given context. When evaluating standart ScholarCopilot, the $k$ most relevant documents according to this distribution are compared to the ground truth, otherwise the top-$k_{SC}$ most relevant documents are passed to the passage retrieval module (for the reported results I use $k_{SC}=2k$, see also \refsec{hyperparameters}). For each of the top-$k$ ranked passages the PR module returns the document from which each passage was taken. These $k$ documents are then compared to the provided ground truth. 

The evaluation is performed on two datasets that each use different strategies for replacing other citations that appear in the citing context. Other citations are either (1) masked using a \mono{[MASK]} token, this is also how \cite{wang2025scholarcopilot} handle citations, or (2) replaced with the abstract of the cited paper, which is done to imitate the generated context the retriever would be given during inference when the model encounters a \mono{[RET]} token. Following the setup in \cite{wang2025scholarcopilot}, the given citing context is not truncated when passed to ScholarCopilot.\footnote{\cite{wang2025scholarcopilot} only use the last sentence of the context when evaluating their baseline models (\mono{BM25} and \mono{E5-Mistral-7B-Instruct}) but use the full context when evaluating ScholarCopilot.} I found that passing the entire context to the PR module reduces performance, thus only the last $w$ tokens of the citing context are used when the PR retriever is prompted to rank a given set of passages.
